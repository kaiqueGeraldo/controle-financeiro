# Evidências de execução

Criar uma subpasta por tarefa executada: CF-005/README.md, por exemplo. Nenhuma evidência de execução das novas tarefas foi criada apenas por planejar o backlog.

Use o [template](../templates/EVIDENCIA.md). Versionar resumos e artefatos pequenos sanitizados. Traces, vídeos, relatórios extensos e screenshots numerosos devem ficar como artefatos de CI com link, execução e revisão correspondentes; não despejar binários grandes no Git. Não publicar cookies, tokens, URLs com segredo ou dados reais.

As [validações anteriores](../../docs/sdd/validacao-deploy.md) continuam no SDD histórico. Não copiá-las como prova de que as novas tarefas foram executadas.
